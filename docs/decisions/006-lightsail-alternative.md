# ADR 006: Authorized Lightsail deployment

Status: accepted, 9 September 2026.

CloudFront creation failed with an account-verification requirement; RDS creation failed under the account plan's backup-retention limit. The user explicitly authorized Lightsail or another AWS alternative. We retained existing F1 resources and created a small Lightsail container service plus private encrypted PostgreSQL instead of changing account plans or exposing the database.

The same React/FastAPI source is packaged into one image with a managed HTTPS origin. A private-network probe and audited ingestion succeeded. ECR and CodeBuild remain the image pipeline. Database passwords are generated by Lightsail through CloudFormation rather than stored as Terraform input. A temporary bootstrap master credential is rotated after ingestion; runtime uses a reader role and verified TLS.

Tradeoffs: a single small node is a development deployment, not highly available production. Lightsail deployment environment contains runtime secrets visible to authorized operators. Runtime logs are continuously available in Lightsail; CloudWatch receives explicit snapshots and build logs. Existing initial infrastructure remains billable pending separately authorized cleanup. Estimated active Lightsail baseline is $30/month, excluding AI usage and retained infrastructure.

# ADR 002 — Temporal evaluation and prediction cutoff

Accepted 2026-09-08. Main fit window 2010–2018, validation 2019–2021, final test 2022–2024. No random row splits. Entire races stay together. Compare candidate features and modern training windows only on validation; freeze selection before evaluating final test. Do not retrain on final test for the demo model. Historical inference before the model's fit cutoff must be refused or use a separately trained walk-forward model.

The task is retrospective post-grid, pre-race podium probability per recorded entrant. Grid is obtained from historical results because there is no independent grid file. It is available conceptually before lights-out, but the snapshot may include retrospective corrections; no claim of live point-in-time provenance is made. Entrant availability itself comes from completed-race records and may include DNS; this selection limitation must stay visible in methodology.

Binary target uses `position` 1–3, not a fabricated label. Grid zero is encoded as 25, a fixed outside-grid proxy for modern pit-lane/unknown/nonstandard starts. No fitted transformation sees held-out data. Metrics include threshold measures at 0.5, probabilistic losses, ten-bin equal-width expected calibration error, and race-wise ranking. Top-three hit rate is correct podium drivers among the three highest-probability drivers; exact podium set ignores finishing order. Probabilities are independent marginals and need not sum to three.

Past test-season results may enter features for subsequent races in that season, matching sequential pre-race availability; they must never fit model parameters. Update history only after all rows for a date have been featurized. No same-day or future outcome influences another row's inputs. This conservative date cutoff avoids assuming race IDs are chronological or that same-day events have trustworthy timestamps.

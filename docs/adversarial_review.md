# Adversarial repository review

Review date: 2026-09-11. Conducted by the implementing Codex agent, not an independent reviewer. This is an evidence-backed self-review, not a faculty or independent security certification.

| Area | Evidence inspected | Finding / disposition |
|---|---|---|
| Target/future leakage | `backend/ml/features.py`, mutation tests, split masks | Outcomes are scoring columns only; feature allowlists select inputs. Same-date rows are emitted before any history update. Train 2010–2018, selection 2019–2021, final 2022–2024; parameters frozen before final evaluation. |
| Rolling semantics | Driver/team/circuit histories and tests | Previous five appearances/races, fixed debut priors. Team aggregates are race-level means across drivers. Career warmup starts 1990, not all history. |
| Point-in-time provenance | CSV audit and inference entry construction | Results snapshot supplies historical grids and participants; original pre-race publication timestamps and correction history are unavailable. This is retrospective pre-race-feature evaluation, not a verified live forecast archive. |
| Predictions and explanations | Saved artifact pipeline, final report, SHAP reconstruction | Real sklearn inference. Calibrated SHAP base and factors reconstruct probabilities within 1e-7. Factors are associative log-odds, not causal explanations. |
| Race probability coherence | `backend/ml/probability.py`, 128-race evaluation, property and mutation tests | A deterministic clipped-logit projection makes each supported race sum to three within floating-point tolerance and preserves ranking. It constrains marginal probabilities; the separate outcome derivation consumes those fixed marginals. |
| Podium outcome boundary | `backend/ml/outcomes.py`, 68-race sweep, strict API and adversarial verifier tests | The maximum-entropy solver enumerates all unordered three-driver subsets and reconstructs every released marginal. All 77,349 sets converged; maximum driver error was `3.82e-13`. No outcome labels or new fit are used. The response marks the set as unordered, non-causal, and not separately validated; it must not be presented as learned driver dependence or a finishing-order forecast. |
| Artifact lineage and public evidence | Manifest hashes, pre-deserialization verifier, readiness, model-card contract and tamper tests | Runtime binds two joblib artifacts and four reports to one version and fails closed on byte or metadata disagreement. Public output is a strict allowlist. The new analysis reuses consumed 2022–2024 outcomes and is labeled post-test iterative, not unseen evidence. |
| Forecast review boundary | Review service call order, same-race/future mutation tests, Monaco contract | Forecasts and factors are generated before results are read. Recorded labels are joined afterward for whole-grid Brier/absolute error and surprises; result mutation cannot change the forecast payload. |
| Grid scenario boundary | Strict request/response models, predictor copy isolation, symmetry, pit-lane proxy and API tests | Callers can select only two distinct race starters. The service swaps their copied `grid_position` inputs, holds every other value fixed, and preserves the released forecast. Actual positions remain separate from transformed inputs, including grid `0` versus proxy `25`. Both whole-field probability sets sum to three. The response states that the result is non-causal, not newly validated, and not a live-race recommendation. |
| Metrics and hypotheses | EXPERIMENTS, saved reports, executed notebooks | No fabricated successes: probability scores improve, top-three hit rate slightly declines; H3 recent form alone does not beat career. Four notebooks executed from production modules. |
| Frontend data | API client, browser network paths and visible rows | Real API payloads throughout. Fixtures are confined to tests. Browser verified standings, race data, comparisons, profiles, predictions, the complete podium-set map, grid scenarios, spelling-aware chat, visible SQL and result charts. |
| SQL mutation boundary | AST validator, SQLite authorizer, live PostgreSQL role test | Single read-only statement, known tables/functions, capped rows and timed execution. SELECT-only PostgreSQL role independently denies DELETE/CREATE. |
| Raw detail policy | Aggregate scope inspection | Found scalar/window aggregate disguises; corrected and covered by three regression cases. Replayed all 30 saved Run 05 SQL queries with unchanged results after the fix. |
| Grounding/hallucination | Bounded router/generator, query augmentation, DB entity/schema retrieval, spelling resolver and live suites | Weather/tyres/fuel/telemetry refused; factual responses render from rows/model. Browser QA found an overlapping `Jackie Lewis` reference in the trace despite the correct answer; a failing catalog regression now suppresses lower-confidence overlapping components/references when a full name is explicit. Model-supplied assumptions remain unverified and labeled. No manual statistical answer mapping. |

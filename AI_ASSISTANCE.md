# AI assistance disclosure

OpenAI Codex assisted source inspection, implementation, tests and documentation. This repository records actual engineering milestones as they happen. AI suggestions are not factual evidence: dataset claims are checked by executable audits, code is run, tests are executed, and reported metrics come from executed project experiments. Agent review is not a claim of independent human review. The worklog identifies completed validation; unfinished functionality is not advertised as implemented. No commits are backdated or manufactured after building the entire system.

Bedrock `openai.gpt-oss-120b` is the application routing and SQL-planning model. Deterministic code augments questions, retrieves stored entities, ranks a relationship-closed schema and enforces a three-call budget. The model does not generate podium probabilities or statistical facts from memory: statistics come from validated read-only SQL, and predictions come from the frozen local model. A rejected SQL plan can receive one bounded repair with only a coarse failure category.

Nine append-only NL2SQL reports and one separate agentic report preserve failed and successful development iterations. Both suites were repeatedly used during development and are not unseen estimates. Reproducibility notebooks were executed retrospectively from production modules and are not presented as a contemporaneous manual experiment diary. CodeBuild supplies actual Linux container validation; AWS readiness is reported only after cloud checks. The UI exposes an allowlisted trace, while prompts, provider payloads, exception text, credentials and request text are excluded from production logs. See `docs/adversarial_review.md` for the implementing agent's scrutiny and its limits.
